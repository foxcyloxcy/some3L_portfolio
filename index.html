Personal · AI & OCR

Behind the project

Built as an independent document-intelligence workflow to transform unstructured documents into reviewable data. The planned pipeline covers upload, OCR, receipt/invoice classification, merchant and country identification, field extraction, validation, and CSV/XLSX/JSON exports. Engineering considerations include handling large uploads, processing errors, diagnostic records and the separation of extracted values from calculated or externally verified fields. This is an actively evolving project; not every planned capability should be interpreted as production-complete.

Key highlights

  • Workflow: document upload → OCR → classification → structured extraction → validation and export.
  • Engineering: file-size handling, diagnostic logging, failure recovery and traceable extracted versus calculated values.
  • Status: independently developed and evolving; functionality varies across builds.

Personal · Chemistry

Behind the project

A Next.js and TypeScript chemistry tool with a searchable 118-element table, element details, molar-mass calculations, formula editing and suggestions. Atomic weights use a documented CIAAW reference snapshot for supported elements. Verified compound names are distinguished from ambiguous or unverified names, with PubChem references where available. The interface is designed to explain calculations without inventing unknown elemental weights or predicting reactions.

Key highlights

  • Interactive 118-element table with search, details and formula editing.
  • Deterministic molar-mass calculations based on supported audited atomic-weight references.
  • Formula suggestions and reviewed compound naming with clear uncertainty labels.

Personal · Browser game

Behind the project

Built a browser-playable interpretation of the classic Nokia 3310 Space Impact experience using Nuxt 3, Vue 3, TypeScript and Canvas. The game features an 84 × 48 pixel LCD-style playfield, eight stage scripts, keyboard and touch controls, enemy waves, special weapons, boss encounters, scoring and synthesized sound effects. Gameplay is continually refined against historical references; sprites, stage timing and behavior are independent approximations rather than a verified, pixel-perfect copy of the original Nokia game.

Key highlights

  • Eight playable stages with individually configured boss encounters and scrolling terrain.
  • Compact LCD-inspired graphics, responsive controls, bombs, rockets, lasers and sound feedback.
  • Deterministic gameplay helpers, automated testing and deployment through GitHub Pages.
